# Security

## Supported versions

Security fixes are provided for the `0.3.0` line on the `main` branch.

## Reporting a vulnerability

Report security issues privately through [GitHub private vulnerability reporting](https://github.com/kchason/iac-stig-automator/security/advisories/new).

Do not open a public issue for a suspected vulnerability. Do not include real Terraform plans or state, credentials, subscription IDs, tenant IDs, or account identifiers in the report.
